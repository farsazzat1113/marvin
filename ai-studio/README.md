# MARVIN AI Studio — MVP

واجهة عربية RTL ومتجاوبة لإدارة أفكار ومشاريع الفيديوهات القصيرة.

## التشغيل
```bash
cd ai-studio
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:
```bash
npm run build
```

## ما يعمل الآن
- لوحة تحكم ومساحة عمل.
- التنقل بين الاستوديو والجدول والقنوات والمكتبة.
- مولّد أفكار تجريبي محلي داخل المتصفح.
- إضافة الأفكار إلى مكتبة المسودات.
- واجهة متجاوبة للموبايل والكمبيوتر.

## حدود النسخة الحالية
هذه واجهة MVP وليست بعد نظام توليد فيديو أو نشر آلي. توليد النصوص حالياً قائم على قوالب محلية، والبيانات تجريبية وغير محفوظة بعد إعادة تحميل الصفحة. لا يوجد تسجيل دخول أو خادم أو ربط حسابات حقيقي في هذه المرحلة.

## مراحل التطوير التالية
1. Backend آمن وتخزين للمستخدمين والمشاريع.
2. موصلات اختيارية لمزودي نماذج AI مع مفاتيح محفوظة على الخادم.
3. توليد سكريبت وكابشن وهاشتاجات فعلي.
4. خط إنتاج فيديو عبر أدوات محلية/مفتوحة المصدر أو مزود خارجي.
5. OAuth الرسمي وجدولة النشر حسب واجهات المنصات وسياساتها.
6. اختبارات، حماية، ونشر.

لا تطلب كلمة مرور TikTok أو YouTube أو Instagram مباشرة من المستخدم، ولا تخزن مفاتيح API داخل كود الواجهة.
