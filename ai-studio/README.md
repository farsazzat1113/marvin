# MARVIN AI Studio

واجهة عربية RTL لإدارة مشاريع الفيديوهات القصيرة، مع محرك توليد محتوى محلي عبر Ollama.

## تشغيل محرك الذكاء الاصطناعي على Windows

1. نزّل وثبّت Ollama من الموقع الرسمي: https://ollama.com/download
2. افتح PowerShell داخل مجلد المشروع.
3. نفّذ:
   ```powershell
   ollama pull qwen2.5:3b
   ```
4. تأكد أن Ollama يعمل، ثم شغّل الواجهة:
   ```powershell
   cd ai-studio
   npm install
   npm run dev
   ```
5. افتح رابط Vite المحلي، ثم ادخل إلى **استوديو المحتوى** واضغط **فحص الاتصال**. النموذج الافتراضي هو `qwen2.5:3b`.

إذا لم يكن Ollama يعمل، افتح تطبيق Ollama من قائمة Start. ويمكن تشغيل الخادم يدوياً من PowerShell بالأمر `ollama serve`.

## ماذا يفعل المحرك الآن؟
- يتصل بـ Ollama المحلي عبر `http://127.0.0.1:11434`.
- يتحقق من اتصال المحرك والنماذج المثبتة.
- يولد 3 أفكار مختلفة حسب المجال والموضوع والمنصة.
- يكتب افتتاحية جذابة وسيناريو قصيراً ووصفاً وهاشتاجات ودعوة للتفاعل.
- يحفظ الفكرة والسيناريو الناتج داخل مكتبة المشاريع المحلية.
- يستخدم استجابة JSON منظمة من واجهة Ollama.

## الخصوصية والتكلفة
- استدلال النموذج المحلي يتم على جهاز المستخدم، ولا يحتاج مفتاح API مدفوعاً.
- تنزيل Ollama والنموذج يحتاج اتصال إنترنت ومساحة تخزين، والتشغيل يستهلك RAM/CPU أو GPU حسب الجهاز.
- لا نرسل كلمات مرور المنصات أو مفاتيح API.
- واجهة الويب المنشورة على استضافة بعيدة لا تستطيع الوصول تلقائياً إلى Ollama على جهازك؛ استخدم نسخة Vite المحلية على `localhost` أو اضبط السماح بالأصول في Ollama بحذر عند الحاجة.

## تشغيل الواجهة وبناء نسخة الإنتاج
```bash
cd ai-studio
npm install
npm run dev
npm run build
```

## المزايا الإدارية
- لوحة تحكم عربية متجاوبة.
- مكتبة مشاريع وحفظ تلقائي محلي.
- استيراد وتصدير نسخ JSON.
- بحث وتصفية حسب حالة المشروع.
- مواعيد تنظيمية محلية؛ لا تنفذ النشر تلقائياً.

## ما لم يُنفذ بعد
- توليد أو تحرير ملفات الفيديو فعلياً.
- تحويل النص إلى صوت.
- OAuth أو النشر التلقائي على YouTube وTikTok وInstagram.
- مزامنة سحابية أو حسابات مستخدمين.

## التحقق
يتم تشغيل `npm install` و`npm run build` عبر GitHub Actions عند تحديث ملفات الاستوديو.
