# MARVIN AI Studio

واجهة عربية RTL ومتجاوبة لإدارة أفكار ومشاريع الفيديوهات القصيرة.

## التشغيل محلياً
```bash
cd ai-studio
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:
```bash
npm run build
```

## ما يعمل في النسخة الحالية
- لوحة تحكم عربية متجاوبة للموبايل والكمبيوتر.
- استوديو أفكار حسب المجال والمنصة.
- إضافة الأفكار إلى مكتبة المسودات.
- حفظ تلقائي للمشاريع في `localStorage` على نفس المتصفح والجهاز.
- حذف المسودات وتصدير نسخة احتياطية بصيغة JSON.
- صفحات تنظيمية للقنوات وجدول النشر.
- فحص بناء تلقائي عبر GitHub Actions عند تغيير ملفات الاستوديو.

## حدود النسخة الحالية
هذه نسخة MVP للواجهة وإدارة المسودات محلياً. اقتراحات الأفكار الحالية قوالب تجريبية وليست ناتجة عن نموذج AI متصل. لا يوجد حتى الآن حسابات مستخدمين أو مزامنة سحابية أو توليد فيديو أو نشر تلقائي. البيانات المحفوظة في المتصفح لا تنتقل تلقائياً إلى جهاز آخر؛ استخدم تصدير JSON للاحتفاظ بنسخة احتياطية.

## مراحل التطوير التالية
1. Backend آمن مع قاعدة بيانات وحسابات مستخدمين.
2. واجهة API لمزودي AI اختيارية، مع حفظ المفاتيح على الخادم فقط.
3. توليد نصوص وسيناريوهات وكابشن وهاشتاجات حقيقية.
4. رفع وإدارة ملفات الفيديو وإضافة خط إنتاج فيديو.
5. OAuth الرسمي وجدولة النشر وفق واجهات المنصات وسياساتها.
6. اختبارات وتدقيق أمني ونشر.

لا تطلب كلمة مرور TikTok أو YouTube أو Instagram مباشرة من المستخدم، ولا تخزن مفاتيح API داخل كود الواجهة.
