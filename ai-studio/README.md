# MARVIN AI Studio

واجهة عربية RTL لإدارة إنتاج الفيديوهات القصيرة. يتضمن المشروع الآن نواة API محلية لإدارة طابور الإنتاج والتواصل مع Ollama.

## التشغيل على Windows

1. ثبّت Ollama من https://ollama.com/download
2. افتح PowerShell داخل مجلد المشروع الرئيسي.
3. نزّل النموذج:
   ```powershell
   ollama pull qwen2.5:3b
   ```
4. شغّل واجهة المستخدم في نافذة PowerShell:
   ```powershell
   cd ai-studio
   npm install
   npm run dev
   ```
5. شغّل الخادم المحلي في نافذة PowerShell ثانية:
   ```powershell
   cd ai-studio
   npm run server
   ```
6. الواجهة على رابط Vite المحلي، وواجهة API على http://127.0.0.1:8787.

## نواة الخادم المحلية

- `GET /api/health`: حالة الخادم واتصال Ollama والنماذج المحلية.
- `GET /api/models`: النماذج المثبتة.
- `POST /api/generate`: توليد 3 أفكار وسيناريوهات وvisual prompts عبر Ollama.
- `GET /api/jobs`: قراءة طابور الإنتاج.
- `POST /api/jobs`: حفظ مشروع إنتاج جديد.
- `PATCH /api/jobs/:id`: تحديث الحالة أو موعد التنفيذ.
- `DELETE /api/jobs/:id`: حذف مشروع.
- `POST /api/jobs/:id/publish`: يرفض النشر حالياً برسالة واضحة حتى يتم إعداد موصل المنصة وتفويض الحساب.

تُحفظ بيانات الطابور محلياً في `ai-studio/.marvin-data/jobs.json`. لا تضع كلمات مرور أو رموز وصول في هذا الملف.

## حدود النسخة الحالية

هذه النواة هي بداية خط الإنتاج وليست بعد نظاماً ينشئ ملفات MP4 أو ينشرها. مراحل إنشاء الفيديو والصوت، OAuth الرسمي، والرفع التلقائي ستضاف كموصلات منفصلة وتُختبر قبل تفعيلها. لا نطلب كلمات مرور حسابات التواصل ولا ننشر بدون تفويض صريح.

## الخصوصية والتكلفة

- Ollama المحلي يعمل على جهازك ولا يحتاج API key مدفوعاً؛ تنزيل النموذج يستهلك إنترنت ومساحة تخزين وموارد الجهاز.
- الخادم يستمع افتراضياً على `127.0.0.1` فقط، ويقبل CORS من واجهة التطوير المحلية المحددة.
- لا تعرّض هذا الخادم للإنترنت مباشرة.
- الواجهة المستضافة عن بُعد لا يمكنها الاتصال تلقائياً بخادم Ollama المحلي.
